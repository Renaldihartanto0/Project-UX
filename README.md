# SlateMarket starter
Prototype marketplace dengan HTML, Tailwind CSS CDN, dan Vanilla JavaScript (tanpa React/Vite/Node).
Buka `index.html` di browser atau gunakan VS Code Live Server. Internet diperlukan untuk Tailwind CDN dan foto Unsplash.
Fitur homepage: responsive, breadcrumb, kategori interaktif, pencarian, sorting, product cards, cart counter localStorage, toast, mobile navigation.
Data produk di `js/data/products.js` masih dummy. Backend, login, pembayaran, dan checkout belum diimplementasikan.
